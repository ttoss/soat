SOAT is open source under the [Apache License 2.0](./LICENSE). That license
covers the **code**, and section 6 explicitly withholds trademark rights. It
does not grant rights to the **name** "SOAT", the SOAT logo, or the
`soat.ttoss.dev` domain, which remain the property of Terezinha Tech Operations
(ttoss).

This policy says what you may do with the name without asking. It exists so that
"SOAT" reliably identifies this project: a modified version advertised as SOAT
misleads the people who trust the name, which is a problem for them before it is
a problem for us.

## You may, without asking

- State that your software uses, integrates with, is built on, or is compatible
  with SOAT — "built on SOAT", "SOAT-compatible", "works with SOAT".
- Use the name to refer to this project in articles, talks, documentation,
  tutorials and comparisons.
- Distribute unmodified copies of SOAT under its own name.
- Keep the name in source files, package metadata and attribution notices; the
  Apache License requires you to retain them.
- Use "SOAT" inside a package or repository name that identifies a genuine
  extension, as long as the name makes clear it is yours and not ours
  (`acme-soat-plugin` is fine, `soat-official` is not).

## You may not, without written permission

- Use "SOAT" as the name of your product, service, company, or a modified
  distribution.
- Register a domain, social account, or package namespace whose primary element
  is "SOAT".
- Use the SOAT logo as your own, or any mark confusingly similar to it.
- Present a modified version as SOAT. Fork freely — the license allows it — but
  ship the fork under your own name and describe it as derived from SOAT.
- Imply endorsement, affiliation, partnership, or certification by ttoss.

## Running SOAT as a service

Hosting SOAT for others is permitted by the Apache License 2.0 and by this policy.
Name the service after yourself rather than after SOAT: "Acme Agent Cloud,
powered by SOAT" is fine; "SOAT Cloud" is not.

## Asking

Uses not listed here are usually granted, with attribution — the point of asking
is that we know who is using the name and how. Open a
[discussion](https://github.com/ttoss/soat/discussions) or contact ttoss.
